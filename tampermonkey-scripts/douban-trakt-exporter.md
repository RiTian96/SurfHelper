# 豆瓣观影数据导出Trakt

## ✨ 主要功能
- **一键导出** - 抓取豆瓣「电影/剧集 × 看过/想看」四类列表，生成 Trakt 官方导入器可识别的 JSON 文件
- **两种浏览模式通吃** - 豆瓣的列表模式（每页 30 条）与网格模式（每页 15 条）页面结构不同，脚本自动识别，评分与标记日期都能正确读取
- **IMDb 自动匹配** - 自动访问豆瓣条目页提取 IMDb 编号，随机间隔防封，无需手工查号
- **断点续传** - 采集清单与 IMDb 结果全部缓存，中断或刷新后可从断点继续，已解析过的条目自动跳过
- **安全验证自动暂停** - 触发豆瓣验证码时自动挂起，手动过验证后点「继续」即可接着跑
- **未匹配清单** - 无 IMDb 编号的条目（华语片、综艺等）单独导出，方便人工补录
- **豆瓣 ID 自动识别** - 打开任意豆瓣页面即可自动填入自己的 ID（从网址或顶栏个人主页链接读取），无需手动查找
- **玻璃拟态面板** - 右上角 🎬 圆形入口与仓库其他脚本保持一致，点击展开，含实时进度条、统计与滚动日志，支持暂停/继续/停止

## 🚀 如何使用
1. **安装脚本** - 点击[安装链接](https://raw.githubusercontent.com/RiTian96/SurfHelper/main/tampermonkey-scripts/douban-trakt-exporter.user.js)，在油猴插件中安装
2. **打开豆瓣任意页面** - 登录豆瓣后访问 `www.douban.com` 或 `movie.douban.com` 任意页面，右上角出现 🎬 圆形按钮
3. **勾选导出范围** - 点击 🎬 展开面板，勾选「电影·看过 / 电影·想看 / 剧集·看过 / 剧集·想看」，确认豆瓣 ID 正确（一般已自动填好）、选择请求间隔档位
4. **开始任务** - 点「开始」，面板会先翻页采集清单（阶段一），再逐条匹配 IMDb（阶段二）。大库需要挂机等待，中途可暂停，不要关闭页面
5. **导入 Trakt** - 任务完成后自动下载 JSON，前往 [Trakt 数据导入页](https://app.trakt.tv/settings/data?mode=media&source=trakt-json) 上传即可（页面 source 需选 `trakt-json`）

> 💡 先小范围试跑：只勾「电影·看过」，确认 JSON 字段与 IMDb 命中率没问题再跑全量。

## 📄 导出字段说明
```json
[
  {
    "imdb_id": "tt0111161",
    "type": "movie",
    "watched_at": "2023-05-01T12:00:00Z",
    "rating": 10,
    "rated_at": "2023-05-01T12:00:00Z"
  }
]
```
- **type** - 电影为 `movie`，剧集（电视剧/动画剧集/综艺）为 `show`
- **watched_at / watchlisted_at** - 取自豆瓣标记日期；豆瓣只给到年月日，统一补 `T12:00:00Z`
- **rating / rated_at** - 豆瓣 5 星制 ×2 换算（很差=2、较差=4、还行=6、推荐=8、力荐=10），未评分的条目不输出这两个字段
- **文件拆分** - 超过 1000 条自动拆成多个文件；无 IMDb 的条目单独写入 `douban_trakt_unmatched_日期.json`

## ⚠️ 注意事项
- 需要登录豆瓣后使用；脚本在 `www.douban.com` 与 `movie.douban.com` 均生效，数据始终从 `movie.douban.com` 读取
- 豆瓣 ID 一般会自动识别；若面板提示未识别到，手动填写个人主页链接 `https://www.douban.com/people/你的ID/` 中那串 ID
- 匹配 IMDb 需要逐个访问条目页，标准档约 1.5–3 秒一条，1000 条约 30–50 分钟，属于正常速度
- 触发豆瓣安全验证时脚本会暂停并在日志给出链接，手动打开完成验证后点「继续」
- 豆瓣标记日期按北京时间记录，导出统一用 `T12:00:00Z`（UTC），与北京实际时间相差约 12 小时，属预期行为
- Trakt 官方导入器主要处理观看历史与关注列表，评分字段可能被忽略
- 面板中的「清缓存」只清除脚本缓存，不会删除已下载的文件
