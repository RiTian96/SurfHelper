## VIP视频解析器 - 优酷平台检查（有头浏览器）

**检查方式**：agent-browser + Edge 有头浏览器，访问 v.youku.com 剧集页面

**优酷当前播放器 DOM 层级**：
```
.player-container (763x438, pos:relative)
  > #ykPlayer (.youku-player, 763x438, pos:relative)
    > .video-layer (763x438) > <video>
    > .advertise-layer (763x438, display:block) ← 广告覆盖层
    > .youku-advertise-layer (763x438, display:block) ← 优酷广告层
    > .advertise-youku-tips (763x438, display:block) ← 广告提示层
    > #subtitle
    > dashboard#youku-dashboard
    > preplay-layer
    > pop-layer
    > VIP-LAYER.kui-vip-layer-0 (display:none) ← VIP遮罩
```

**发现的问题**：
1. **startGuardian 缺少优酷选择器** — targetRef 和 searchList 都没有 `.player-container`, `#ykPlayer`, `.youku-player`，仅靠通用选择器 `.player-container` 碰巧在 searchList 末尾
2. **nuisanceSelectors 优酷部分全部失效** — `.covers_cloudCover__ILy8R`/`.youku-player-vip-tip`/`.yk-player-vip-overlay` 当前页面都不存在
3. **缺少优酷广告层清理** — `.advertise-layer`/`.youku-advertise-layer`/`.advertise-youku-tips` 都是 763×438 的全屏覆盖层，display:block，不在 nuisanceSelectors 中
4. **缺少优酷换集检测** — setupHistoryListeners 中只有爱奇艺/腾讯/芒果TV/B站，没有优酷
5. **优酷选集链接新格式** — 选集链接从 `v_show/id_XXX` 变为 `video?vid=XXX`（但最终会重定向回 v_show 格式），点击检测需匹配新格式
6. **playerContainerSelectors 是死代码** — 声明了但从未被引用，实际容器查找在 startGuardian 中硬编码
